# My-Personal-Portfolio_Website

Welcome to my **personal portfolio website**! 🚀

This portfolio is designed to showcase my **education, skills, projects, services, and software development journey** through a clean, modern, and responsive interface.

The website focuses on a dark gradient design with a **teal accent color**, interactive components, smooth animations, and responsive layouts for different screen sizes. 💻📱

---

## 🌐 Live Website

🔗 **Visit my portfolio:**
https://abdullahawaisdev.github.io/Developer-Portfolio-Frontend-Design/

---

## ✨ Features

* 🏠 **Home Section** — Introduction and quick access to projects/contact
* 👤 **About Me** — Personal introduction and current learning journey
* 🎓 **Education Section** — Academic background and achievements
* 🛠️ **Skills Section** — Technologies and tools I'm learning/using
* 💼 **Projects Section** — Showcase of my frontend projects
* 🚀 **Services Section** — Services I can provide
* 📩 **Contact Section** — Email, phone, GitHub, LinkedIn, and location
* 📄 **Resume Download** — Downloadable PDF resume
* 🎨 **Modern Dark UI** — Gradient-based dark theme with teal accents
* 📱 **Responsive Design** — Adapted for desktop, tablet, and mobile screens
* 🎞️ **Slick Slider** — Responsive project carousel
* ✨ **AOS Animations** — Scroll-based section animations
* 💫 **Animate.css** — Animation library integration
* 🔔 **SweetAlert2** — Interactive resume download notification
* 🖱️ **Custom Cursor** — Animated cursor effect for desktop
* ⬆️ **Back-to-Top Button** — Quickly return to the home section
* ⏳ **Preloader** — Loading screen displayed while the website loads
* 📜 **Custom Scrollbar** — Styled scrollbar matching the website theme
